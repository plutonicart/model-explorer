# Размещение Model Explorer на GitHub Pages

Сайт пока не опубликован. Архив `Model_Explorer_GitHub_Pages.zip` содержит готовые файлы сайта; Python и сборка на компьютере для публикации не требуются.

1. Распакуйте архив в отдельную папку. В ней должны быть `index.html`, папки `assets` и `data`, страница `comparison.html` и сопроводительные файлы.
2. Создайте на GitHub пустой публичный репозиторий, например `model-explorer`. Для бесплатного аккаунта используйте публичный репозиторий.
3. Загрузите **содержимое распакованной папки**, сохранив вложенные папки. Не загружайте сам ZIP вместо файлов. `index.html` должен оказаться в корне репозитория. Создайте commit в ветке `main`.
4. В репозитории откройте **Settings → Pages**. В разделе **Build and deployment → Source** выберите **Deploy from a branch**; затем ветку **main**, папку **/(root)** и **Save**.
5. Дождитесь успешной публикации. GitHub покажет адрес сайта в том же разделе Pages. Откройте его и проверьте три группы в списке: всего 15 сценариев.

Вместе с файлами желательно загрузить пустой файл `.nojekyll`, включённый в архив. В Windows он может быть скрыт. Сайт использует относительные пути и рассчитан на размещение в подпапке проекта.

Если сайт не открывается, сначала проверьте, что `index.html` находится в корне выбранной ветки, а не внутри ещё одной папки. Если открылась оболочка, но нет кривых, проверьте наличие 15 JSON-файлов в папке `data`.

Проверка после публикации: выбрать по сценарию TAK-632, Encorafenib и Cobimetinib; проверить клеточный контекст и KSR1; выбрать точку на графике; открыть сведения реакции; включить сравнение пяти уровней; переключить время/концентрацию. Подробности расхождений с рисунком доступны по ссылке Figure comparison and validation.

Официальная инструкция GitHub, проверенная 25.11.2026: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site
